# -Visa-Approval-Predictor
Machine Learning-Based Visa Approval Prediction. Develop a classification model to predict visa approval status, helping streamline the candidate shortlisting process. Cleaned and processed large-scale visa application datasets from OFLC for insightful analysis. 


✅ Engineered key features to enhance model interpretability and decision-making.
✅ Tune model hyperparameters to achieve accuracy improvement over baseline models.
✅ Evaluate model performance using precision, recall, F1-score, and confusion matrices.
✅ Deliver actionable insights for visa approval recommendations, aiding in faster decision-making
